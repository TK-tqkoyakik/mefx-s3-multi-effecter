MEFX-S3 作成前チェック
=======================

判定
----
現時点では、ブレッドボード/ユニバーサル基板で「電源だけ」から段階的に作成へ進んでよい状態です。
ただし、ケース加工、基板発注、全部品を一気に接続する作業はまだしません。

最初に作る範囲は以下だけです。

1. 9V入力、MP1584、+5V、ESP32の+3.3V確認
2. 10kΩ/10kΩの4.5V仮想GND確認
3. TL072入力プリアンプ単体確認
4. PCM1808/PCM5102A/I2S接続
5. 最後に出力ジャック接続


今回直した問題
--------------
1. ファームウェアのフットスイッチGPIOを GPIO0 から GPIO9 に修正しました。
   GPIO0は起動モードに関係するため、フットスイッチには使いません。

2. ファームウェアのI2Sを、設計資料と同じピンに修正しました。
   - GPIO17: MCLK
   - GPIO4: BCLK
   - GPIO5: LRCK
   - GPIO6: PCM1808 DOUT -> ESP32入力
   - GPIO16: ESP32出力 -> PCM5102A DIN

3. PCM1808に必要なMCLK/SCKIをファームウェアから出すようにしました。

4. 部品表のコンデンサ個数を修正しました。
   - 100nFセラミック50V: 8
   - 1uFフィルム50V: 2
   - 10uF電解16V以上: 2
   - 47uF電解16V以上: 2
   - 100uF電解16V以上: 2

5. SVG図面の F1 と D2 を、最小構成では未購入でよい表記に修正しました。
   - JP1/F1 opt: 最小構成ではジャンパー線
   - D2 opt: 最小構成では未実装

6. SVG図面の R20〜R24 を、最小構成ではジャンパー線として表記しました。
   I2Sが不安定な場合だけ33Ω抵抗へ変更します。

7. PCM1808/PCM5102Aモジュールの電源・設定ピンを追記しました。

8. sim/mefx_vbias_v2.cir の仮想GND抵抗を、資料と同じ 10kΩ/10kΩ に修正しました。

9. PCM5102A出力を、TL072 B側バッファ経由から直接出力へ変更しました。
   PCM5102AはGND中心のライン出力を持つため、最小構成では出力カップリングとTL072 B側バッファを使いません。


作成前に買う部品の注意
----------------------
以下を満たさない部品は買わないでください。

1. ESP32-S3開発ボード
   GPIO17、GPIO4、GPIO5、GPIO6、GPIO16、GPIO9 が使えるもの。
   基板上で別用途に固定されているピンしか出ていないものは避けます。

2. PCM1808 ADC I2Sモジュール
   SCKIまたはMCLK端子があるもの。
   SCKI/MCLK端子がないモジュールは、この設計では使いません。

3. PCM1808電源
   VCC/5V、VDD/3.3V、GNDが分かるもの。
   モジュール説明が不明なものは避けます。

4. PCM5102A DAC I2Sモジュール
   BCK、LCK/LRCK、DIN、SCK、GND、VCCが分かるもの。
   XMT/XSMTが露出している場合は+3.3Vへ10kΩでプルアップします。

5. MP1584
   可変式で、ESP32をつなぐ前に5.0Vへ調整できるもの。

6. 9V ACアダプター
   エフェクター用センターマイナス。
   実際のDCジャックの端子はテスターで確認してから配線します。


RC計算による机上確認
-------------------
この計算は、作成前の目安です。実機では必ず音と電圧を確認します。

1. 入力カップリング C10 100nF / R2 1MΩ
   低域カットは約1.6Hzです。
   ギター/ベースの音域にはほぼ影響しません。

2. PCM1808入力 C13/C17 1uF
   PCM1808の入力インピーダンスを約60kΩとして見ると、低域カットは約2.7Hzです。

3. ADC前ローパス R6/R7 100Ω + C14/C18 10nF
   カットオフは約159kHzです。
   音声帯域より上のノイズを軽く落とす目的です。

4. PCM5102A直接出力 R35 100Ω / R36 100kΩ
   PCM5102AはGND中心のライン出力なので、出力カップリングによる低域カットはありません。
   R35は短絡保護と発振/ノイズ対策、R36は出力の基準をGNDへ落とすために使います。

5. 仮想GND R50/R51 10kΩ + C9A 47uF
   VBIAS_4V5は約4.5Vになります。
   電源投入直後に少しゆっくり安定します。


実機で必ず測るところ
--------------------
部品を接続する前に、以下を1つずつ確認します。

1. MP1584 OUT+
   5.0V付近であること。
   5.2Vを大きく超える場合はESP32を接続しません。

2. ESP32 3V3
   3.3V付近であること。

3. VBIAS_4V5
   4.5V付近であること。
   4.0V未満または5.0V超えならTL072を接続しません。

4. TL072 pin8
   +9V付近であること。

5. TL072 pin4
   GNDであること。

6. TL072 pin5
   VBIAS_4V5付近であること。

7. TL072 pin6 と pin7
   直結されていること。

8. OUTPUTジャック Tip
   アンプにつなぐ前にDC電圧を測ります。
   GNDに対して大きなDCが出ていたらアンプへ接続しません。
   PCM5102A直接出力なので、通常はGND付近になる想定です。


作業を止める条件
----------------
以下のどれかが出たら、次へ進まず原因確認します。

1. MP1584出力が5.0Vに調整できない。
2. ESP32の3.3Vが出ない。
3. VBIAS_4V5が4.5V付近にならない。
4. TL072が熱くなる。
5. PCM1808/PCM5102Aモジュールが熱くなる。
6. OUTPUT Tipに大きなDC電圧が出る。
7. ESP32ログでI2S初期化エラーが出る。
8. PCM1808モジュールにSCKI/MCLK端子がない。
