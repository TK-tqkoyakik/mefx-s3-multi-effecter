MEFX-S3 ケース現物合わせ・ジャック配置修正 07
============================================

結論
----
この資料はケースへ入れる段階で使う。
現段階ではケースを後回しにして、基板を表向きで机上確認する。

ケースの左右表記だけでINPUT/OUTPUTを決めない。
今回から、接続するジャックは「基板の部品に当たらない側」へ取り付ける。
ESP32だけは表側に取り付ける。
基板を最優先にして、ケース側を合わせる。

電気的な役割はケースの左右ではなく、基板の端子台で決まる。

- J2へ配線したジャック = INPUT
- J5へ配線したジャック = OUTPUT
- J1へ配線したDCジャック = 9V電源

つまり、物理的に右側にあるジャックでもJ2へつなげばINPUT。
物理的に左側にあるジャックでもJ5へつなげばOUTPUT。


優先順位
--------
1. 基板を守る。
   - 基板を削らない。
   - 基板を曲げない。
   - 実装済み部品へジャックや配線を当てない。
   - ESP32やU5へケースから力をかけない。

2. 電気接続を守る。
   - J1/J2/J5の端子番号を優先する。
   - DC電源のセンターマイナスを必ず守る。
   - INPUT/OUTPUTはケースの左右ではなく配線先で決める。

3. ケースを合わせる。
   - 穴が左右逆に見える場合は、ラベルと配線で対応する。
   - 干渉する場合は、ケース穴の追加/拡張、ワッシャー、配線の取り回しで逃がす。
   - 基板側を加工して合わせるのは最終手段にしない。基本的にやらない。


現物ケースでの進め方
--------------------
1. 基板をケースに仮置きする。
   - ESP32のUSB端子がケースのUSB開口側へ向くことを確認する。
   - 基板固定穴4か所がケースの支柱と合うことを確認する。

2. INPUT/OUTPUTジャックを仮差しする。
   - ジャック本体がIC、抵抗、コンデンサ、ESP32、端子台に当たらないか見る。
   - プラグを挿した状態でも、基板や部品へ力がかからないか見る。
   - 2mm以上のすき間がある状態を目安にする。

3. ジャック本体が部品側に来てしまう場合は、その配置では固定しない。
   - 部品がない側、または干渉しない側の穴を使う。
   - INPUT/OUTPUTの左右が逆に見えても、配線で正しく決める。
   - どうしても干渉する場合は、既存穴を使わず新しく9.8mm穴を開ける。
   - 基板や実装部品を削って合わせない。

4. 配線する。
   - J2-1 -> INPUTジャック TIP
   - J2-2 -> INPUTジャック SLEEVE
   - J5-1 -> OUTPUTジャック TIP
   - J5-2 -> OUTPUTジャック SLEEVE
   - J1-1 -> DCジャック外周端子（+9V）
   - J1-2 -> DCジャック中心端子（GND）

ESP32の向き
-----------
現行の07基板では、ESP32-S3開発ボードを裏側へそのまま挿さない。

理由:
- U3ソケットは「上面にESP32を挿す」前提でピン番号とネットを割り当てている。
- 裏側から同じ穴へ挿すと、物理的には鏡写しになりやすい。
- その場合、+5V、GND、GPIO、I2S信号が別ピンへ入れ替わる可能性がある。
- 電源ピンが入れ替わるとESP32や基板を破損する。

今回のケースでは、ESP32は上面へ挿す。
ジャック本体は、部品がない側または干渉しない側へ逃がして固定する。

将来、次版基板でESP32を裏側へ置きたい場合:
- 次版基板でU3フットプリントを裏面実装用に作り直す。
- USB-C開口位置も裏面実装に合わせてケースを作り直す。
- アンテナ下には銅箔・部品・金属ケースを置かない。
- CPL/PCBAではなく、ESP32ソケットは手はんだ部品として扱う。

5. 外側にラベルを貼る。
   - J2へつながった穴に INPUT と貼る。
   - J5へつながった穴に OUTPUT と貼る。
   - ケースの元の左右イメージと違っても、このラベルを正とする。


絶対に確認すること
------------------
- DC電源はセンターマイナス。
  - プラグ外周 -> J1-1
  - プラグ中心 -> J1-2
- INPUT/OUTPUTのTIPとSLEEVEをテスター導通で確認する。
- ジャックを締めたあと、基板部品に接触していない。
- フタを閉めても、配線が押しつぶされない。
- ESP32を挿す前に、J1-1/J1-2が短絡していない。


今回の扱い
----------
このケースは「現物合わせ」で進める。
左右が逆に感じる場合でも、穴を機能名で固定せず、端子台への配線でINPUT/OUTPUTを決める。
部品に当たる配置は採用しない。
ESP32は現行基板では上面装着を正とする。
今回の組立方針は「ESP32だけ表、ジャック類は干渉しない側」。
基板を正として、ケース側で調整する。
