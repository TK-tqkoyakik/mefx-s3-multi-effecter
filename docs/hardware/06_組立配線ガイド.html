MEFX-S3 組立・配線ガイド 06

正式PCB/PCBA 07とJLC3DPケース07を、部品到着後そのまま組み立てるための資料です。現物ケースでは、INPUT/OUTPUTの左右より端子台への配線を優先します。

ESP32は最初から挿さないでください。9V、5V、極性、短絡を確認してから最後に挿します。
現段階ではケース固定は後回し。まず基板を表向きで机上確認します。J2へつないだ方がINPUT、J5へつないだ方がOUTPUTです。

1. 全体配置

2. 基板へ付ける部品

場所取り付ける物向き・注意
U31x20、2.54mm雌ソケット x22列を平行にする。ESP32のUSB端子は基板左端のUSB表示側。
U5R-78E5.0-1.0左から 1=IN、2=GND、3=OUT。逆向き禁止。
J1～J5KF128-2P 2.54mm端子台線の差込口を基板外側へ向ける。

3. ケース部品と配線

今はケース固定せず机上で仮配線します。物理的な左/右ではなく、J2へつないだ方をINPUT、J5へつないだ方をOUTPUTとして扱います。

ケース部品基板端子接続
9V DCジャックJ1J1-1 +9V → 外周
J1-2 GND → 中心
3端子型のスイッチ端子は未接続。
INPUT 6.35mm TSJ2J2-1 → TIP（先端）
J2-2 → SLEEVE（根元・外周）
エレクトレットマイクJ3J3-1 → ＋
J3-2 → －/外装側
モーメンタリーNOスイッチJ4J4-1/J4-2をNO接点の両端へ。極性なし。
OUTPUT 6.35mm TSJ5J5-1 → TIP（先端）
J5-2 → SLEEVE（根元・外周）
センターマイナスです。DCジャックの中心へ+9Vを接続すると基板を破損する可能性があります。

4. ジャック端子の見分け方

6.35mm TSジャック

  • TIP: プラグ先端へ触れる接点
  • SLEEVE: プラグ根元・金属外周へつながる接点

商品によって端子位置が違うため、外見だけで決めずテスターの導通モードで確認します。

DCジャック

  • 中心端子: プラグの内側へ導通 → GND
  • 外周端子: プラグ外側へ導通 → +9V
  • スイッチ端子: 今回は未接続

5. 組立順

  1. JLCPCB実装部品を目視確認。
  2. ESP32を治具として雌ソケット2本を平行に合わせ、端だけ仮はんだ。
  3. 傾きを直して全ピンをはんだ付けし、ESP32を抜く。
  4. U5を1=IN、2=GND、3=OUTの向きではんだ付け。
  5. J1～J5端子台を外向きにはんだ付け。
  6. ケースへインサートナット、ジャック、スイッチ、マイクを固定。
  7. AWG24撚り線で上表どおり配線。信号線とGNDは軽くねじる。
  8. ESP32なしで短絡・9V・5Vを測定。
  9. 電源を切り、ESP32をUSB表示側に合わせて挿す。
  10. 基板をM3x6mm、フタをM3x12mmで固定。

6. 通電前チェック

  • J1-1とJ1-2が短絡していない
  • DCプラグ外周からJ1-1へ導通する
  • DCプラグ中心からJ1-2へ導通する
  • INPUT/OUTPUTのTIPとSLEEVEを逆にしていない
  • マイクの＋/－が正しい
  • フットスイッチは離すと非導通、押すと導通
  • U5の向きが1=IN、2=GND、3=OUT
  • ESP32をまだ挿していない

7. 初回測定

測定場所正常値
J1-1 → J1-2約+9V
U5 pin 1 → GND約+9V
U5 pin 3 → GND約+5V

異臭、発熱、大電流がなく5Vが正常なら、電源を切ってESP32を挿します。
