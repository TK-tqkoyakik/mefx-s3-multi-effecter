MEFX-S3 4本足端子台対応メモ 15
=============================

状況
----
届いた端子台の足が4本。
一方、MEFX-S3基板のJ1からJ5は、それぞれ2穴だけ。

基板データ上も以下の通り、各端子は2パッドだけ。

- J1: 9V DC / Pad 1 = +9V_RAW / Pad 2 = GND
- J2: INPUT / Pad 1 = INPUT_TIP / Pad 2 = GND
- J3: ELECTRET MIC / Pad 1 = MIC_BIAS / Pad 2 = GND
- J4: FOOTSW / Pad 1 = FOOTSW_GPIO / Pad 2 = GND
- J5: OUTPUT / Pad 1 = OUTPUT_TIP / Pad 2 = GND

結論
----
4本足端子台は、そのまま基板へ付けない。
初回動作確認では、J1からJ5へ短い線を直接はんだ付けする方法が安全。


やってはいけないこと
--------------------
- 基板に追加穴を開ける。
- 4本足を無理に曲げて2穴へ押し込む。
- 足が浮いた状態で強引にはんだを盛る。
- どの足がどの極か確認せずに切る。


使う場合の判断
--------------
4本足端子台をどうしても使う場合は、先にテスター導通モードで足の関係を確認する。

確認パターン:

1. 2本だけが電気端子、残り2本が固定用の足
   - 固定用の足を切れば使える可能性が高い。

2. 4本すべて金属端子で、2本ずつ同じ極につながっている
   - 片方の極から1本、もう片方の極から1本を残す。
   - 残す2本の間隔が基板穴2.54mmに合うか確認する。
   - 合わないなら使わない。

3. どれがどの極か分からない
   - 使わない。
   - 短い線を直接はんだ付けする。


今回の推奨作業
--------------
初回電源確認:
- J1-1へ赤線を直接はんだ付け。
- J1-2へ黒線を直接はんだ付け。
- 赤線をDCジャック外周端子へ。
- 黒線をDCジャック中心端子へ。

音声確認:
- J2からJ5も、まずは端子台なしの仮配線でよい。
- 音が出て、基板が生きていることを確認してから、端子台をどう固定するか考える。


あとで見た目を整える方法
------------------------
- 2本足の2.54mm端子台を買い直す。
- 2.54mm 2ピンのピンヘッダを立てて、デュポン線で接続する。
- 端子台を加工して2本足化し、ホットボンドで補強する。

試作1台目では、見た目より壊さないことを優先する。
