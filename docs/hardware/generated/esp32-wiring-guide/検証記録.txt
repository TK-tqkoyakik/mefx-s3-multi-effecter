MEFX-S3 画像配線ガイド 検証記録

基板・07接続CSV・現行ファームウェアを照合。9接続すべて一致。
U3: 40パッド、2.54mmピッチ、列間25.4mm、表面、USB左。
U3-20 (ESP32 3V3) は未接続。U4の3.3V出力と追加接続しない。
基板SHA256: f5691e27672119531a06d8d6cd6c48e6519275b7eacad75cca4e0cd04038ea51

接続:
U3-1 / +5V -> ESP32 5V (上列 USB側から1穴目)
U3-21 / GND -> ESP32 GND (下列 USB側から1穴目)
U3-12 / MCLK -> ESP32 17 (上列 USB側から12穴目)
U3-18 / BCLK -> ESP32 4 (上列 USB側から18穴目)
U3-17 / LRCK -> ESP32 5 (上列 USB側から17穴目)
U3-16 / ADC_DOUT -> ESP32 6 (上列 USB側から16穴目)
U3-13 / DAC_DIN -> ESP32 16 (上列 USB側から13穴目)
U3-14 / CODEC_RST -> ESP32 15 (上列 USB側から14穴目)
U3-7 / FOOTSW_GPIO -> ESP32 9 (上列 USB側から7穴目)

実物写真で確認した範囲: USB左、アンテナ右、端子印字が設計の並びと整合。
未確認: 裏面のはんだ、ソケットへの挿入、導通、電圧、起動、音出し。
3Dは取り付け説明用の簡略モデル。ソケット高さ・外形の実測や干渉保証ではない。
USB給電だけで完成回路を駆動する案内ではない。書込み時は基板からESP32を外す。
