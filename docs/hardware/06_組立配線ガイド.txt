MEFX-S3 組立・配線ガイド 06
============================

この資料の対象
--------------
- 正式PCB: docs/kicad/mefx_s3.kicad_pcb
- 正式ケース: docs/pcb-assembly/07_order_package/case_3d_print/
- 見やすい図: docs/hardware/06_組立配線ガイド.html
- ケース現物合わせ: docs/hardware/07_ケース現物合わせ_ジャック配置修正.txt
- 先に基板だけ確認: docs/hardware/10_基板表向き_ケース後回し手順.txt

最重要
------
- 基板へ通電する前に、必ずテスターで短絡と極性を確認する。
- ESP32は電源確認が終わるまでソケットへ挿さない。
- 基板を最優先にする。ケースやジャック位置が合わない場合でも、基板を削る、無理に曲げる、部品へ力をかける作業はしない。
- 合わない部分はケース穴、外側ラベル、配線長、ジャックの向きで調整する。
- 現段階ではケース固定を後回しにしてよい。まず基板を表向きで机上確認する。
- 9V電源はセンターマイナス。DCジャック外周が+9V、中心がGND。
- J1からJ5の端子台は、基板シルクの「1」「2」を確認して接続する。
- ケースの左右表記より、基板端子台の番号を優先する。
- INPUT/OUTPUTジャックは、ジャック本体が部品に当たらない「部品がない側」へ取り付ける。
- J2につないだジャックがINPUT、J5につないだジャックがOUTPUT。ケースの左/右だけで判断しない。

基板へはんだ付けする部品
------------------------
1. U3位置: 1x20ピン雌ソケット x2
   - 2列が平行、垂直になるようにはんだ付けする。
   - ESP32はまだ挿さない。
   - ESP32を挿すときはUSB端子を基板左端の「USB」表示側へ向ける。
   - 現在の07基板では、ESP32を裏側へそのまま挿さない。
     ピン配置が鏡写しになり、+5V/GND/GPIOが入れ替わる可能性がある。
   - ESP32を裏側に置く場合は、次版基板でU3を裏面実装用に再設計する。

2. U5位置: R-78E5.0-1.0 x1
   - 基板を文字が読める向きで見た場合、左から次の順。
   - 1=IN（+9V_PROT）
   - 2=GND
   - 3=OUT（+5V）
   - 逆向きに取り付けない。

3. J1からJ5: KF128-2P 2.54mm端子台 x5
   - 配線差込口を基板の外側へ向ける。
   - J1=9V DC
   - J2=INPUT
   - J3=MIC
   - J4=FOOTSW
   - J5=OUTPUT

ケースへ取り付ける部品
----------------------
- INPUT/OUTPUTジャック:
  - 直径9.8mm穴へ取り付ける。
  - 左右の穴名ではなく、ジャック本体が基板部品に干渉しない側を優先する。
  - J2に配線した方がINPUT、J5に配線した方がOUTPUT。
  - 穴が左右逆に見える場合でも、配線先を正しくすれば電気的には問題ない。
- 9V DCジャック:
  - 直径8.5mm穴へ取り付ける。
  - 可能なら部品やESP32に当たらない側へ逃がす。
- フタ中央: モーメンタリーNOフットスイッチ
- フタの直径4mm音孔の裏: 6x5mmエレクトレットマイク

ケースから基板への配線
----------------------

J1 9V DC
- J1-1（+9V_RAW） -> DCジャックの外周端子
- J1-2（GND）     -> DCジャックの中心端子
- DCジャックに3つ目のスイッチ端子がある場合は使用しない。
- センターマイナスなので中心を+9Vへ接続してはいけない。

J2 INPUT
- J2-1（INPUT_TIP） -> INPUTジャックのTIP端子
- J2-2（GND）       -> INPUTジャックのSLEEVE端子
- TIPはプラグ先端、SLEEVEはプラグ根元/ジャック金属外周。
- ケース上で左にあるか右にあるかは関係ない。J2へつながっているジャックをINPUTとして外側にラベルを貼る。

J3 ELECTRET MIC
- J3-1（MIC_BIAS） -> マイクのプラス端子
- J3-2（GND）      -> マイクのマイナス端子/ケース側
- 一般的なエレクトレットマイクは、外装へつながる端子がマイナス。

J4 FOOTSW
- J4-1（FOOTSW_GPIO） -> NO接点の片側
- J4-2（GND）         -> NO接点の反対側
- 極性なし。
- 押した間だけJ4-1とJ4-2が導通する端子を使用する。

J5 OUTPUT
- J5-1（OUTPUT_TIP） -> OUTPUTジャックのTIP端子
- J5-2（GND）        -> OUTPUTジャックのSLEEVE端子
- ケース上で左にあるか右にあるかは関係ない。J5へつながっているジャックをOUTPUTとして外側にラベルを貼る。

推奨配線色
----------
- 赤: +9V
- オレンジ: +5V系（外部配線には通常使用しない）
- 黒: GND
- 白: INPUT TIP
- 青: OUTPUT TIP
- 黄: FOOTSW GPIO
- 緑: MIC BIAS

配線の作り方
------------
- AWG24撚り線を使用する。
- ケース部品から基板まで、分解できる余裕として約80から120mm確保する。
- 信号線とGNDは2本を軽くねじる。
- INPUT線は9V配線やDC/DCから離す。
- INPUT/OUTPUT線は、部品が載っている面を強く横切らせず、ケース端に沿わせて逃がす。
- はんだ付け部へ熱収縮チューブを被せる。
- ケースの角やねじに線を挟まない。

組立順
------
0. ケースにはまだ固定しない。基板を表向きに置き、机上で確認する。
1. JLCPCB実装部品の向き、はんだブリッジ、破損を目視確認する。
2. U3雌ソケット2本を仮挿しし、ESP32を治具として使って平行を合わせる。
3. ソケットの端1本ずつを仮はんだし、傾きを直してから全ピンをはんだ付けする。
4. ESP32をいったん抜く。
5. U5 R-78E5.0-1.0を正しい向きではんだ付けする。
6. J1からJ5の端子台を、配線差込口が基板外側を向くようにはんだ付けする。
7. ケース固定は後回し。INPUT、OUTPUT、DCジャック、フットスイッチ、マイクは机上で仮配線する。
8. 各部品から基板端子台へ配線する。
9. ESP32を挿さずに電源確認を行う。
10. 問題がなければ電源を切り、ESP32をUSB側表示に合わせて挿す。
    - ESP32は07基板では上面へ挿す。
    - 裏面へ直接挿す組み方はしない。
11. ファームウェア、BLE、フットスイッチ、音声入出力を確認する。
12. 音が出てから、ケース固定と穴位置を考える。

通電前テスター確認
------------------
電源を接続しない状態:
- J1-1とJ1-2が短絡していない。
- INPUT TIPとGNDが完全短絡していない。
- OUTPUT TIPとGNDが完全短絡していない。
- フットスイッチを離した状態でJ4-1/J4-2は非導通。
- フットスイッチを押した状態でJ4-1/J4-2は導通。
- DCプラグを挿した状態で、J1-1はプラグ外周、J1-2はプラグ中心へ導通する。

初回電源確認
------------
- 電流制限可能な9V電源があれば100mA程度から開始する。
- ESP32を挿さずに9Vを接続する。
- J1-1対GND: 約+9V
- U5 pin 1対GND: 約+9V
- U5 pin 3対GND: 約+5V
- 異臭、発熱、大電流があれば直ちに電源を抜く。
- 5Vが正常なら電源を切ってESP32を挿す。

ケース穴と購入部品の条件
------------------------
- INPUT/OUTPUT穴: 直径9.8mm。ジャックねじ部外径9.5mm以下。
- DC穴: 直径8.5mm。DCジャックねじ部外径8.2mm以下。
- ケース壁: 3mm。各部品は3mm厚パネルへナット固定できること。
- フットスイッチ穴: 直径12.4mm。M12モーメンタリーNO。
