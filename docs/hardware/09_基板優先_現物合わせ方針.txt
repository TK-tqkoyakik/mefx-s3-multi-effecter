MEFX-S3 基板優先の現物合わせ方針 09
==================================

基本方針
--------
高価で壊れると困る順に守る。

1. PCBA基板
2. ESP32-S3開発ボード
3. 電源まわり
4. ジャック/スイッチ/配線
5. ケース

今回の組立では、基板を基準にしてケース側を合わせる。
ケースの穴や左右表記が合わない場合でも、基板を削ったり、部品に力をかけたりしない。
ただし現段階では、ケース固定は後回しにする。
まず基板を表向きで机上確認し、電源と動作が確認できてからケースへ入れる。


採用する組み方
--------------
- ESP32-S3は表側に取り付ける。
- INPUT/OUTPUTジャックは、まずケースへ固定せず机上で仮配線する。
- ケースへ入れる段階では、基板部品に当たらない側へ取り付ける。
- INPUT/OUTPUTの機能はケースの左右ではなく配線先で決める。
  - J2へ配線したジャック = INPUT
  - J5へ配線したジャック = OUTPUT
- DCジャックはセンターマイナスを守る。
  - J1-1 = +9V、DCジャック外周
  - J1-2 = GND、DCジャック中心


やってよい調整
--------------
- ケース穴を追加する。
- ケース穴を少し広げる。
- 外側ラベルを貼り替える。
- ジャックの向きを変える。
- 配線を長めにして、ケース端へ逃がす。
- ワッシャーやスペーサーでジャックの出っ張りを調整する。


やらない調整
------------
- 基板を削る。
- 基板を曲げる。
- 実装済み部品にジャックを接触させる。
- ESP32を裏側へ無理に挿す。
- 端子台へ横方向の強い力をかける。
- 電源確認前にESP32を挿す。


判断基準
--------
迷ったら、基板を守る方を選ぶ。

ケースは加工できる。
配線はやり直せる。
ラベルは貼り替えられる。
でも基板の実装部品や電源系を壊すと復旧が難しい。

今回の正解:
「基板優先。まず表向きで机上確認。ケースは音が出てから考える。」
