MEFX-S3 Amazon購入部品一覧 05
================================

更新日: 2026-06-19

重要
----
- Freenove ESP32-S3 Board Lite（ASIN B0FRRH9NCP）は所持済み。追加購入しない。
- JLCPCBで実装される抵抗、コンデンサ、TL072、CS4270、AP2112K、SS14はAmazonで買わない。
- Amazonの商品名だけでは寸法を確定できない。商品画像の寸法図が下記条件を満たす物だけ購入する。
- 現在、Codex内ブラウザからAmazonへ接続できないため、価格・在庫・ASINは未確定。

優先購入（本体1台分）
----------------------

1. 6.35mmモノラル・パネルジャック: 2個
   推奨型番: REAN NYS229、または同寸法品
   必須条件:
   - モノラル TS
   - ねじ部外径9.5mm以下（ケース穴9.8mm）
   - 3mm厚パネルへナット固定可能
   - ナット/ワッシャ外径が穴より十分大きい
   Amazon検索:
   https://www.amazon.co.jp/s?k=REAN+NYS229
   https://www.amazon.co.jp/s?k=6.35mm+モノラル+パネルジャック+ナット

2. DCパネルジャック: 1個
   推奨型: DC-022B相当
   必須条件:
   - 5.5mm外径/2.1mm内径
   - ねじ部外径8.2mm以下（ケース穴8.5mm）
   - 3mm厚パネルへナット固定可能
   - 3端子でも使用可能だが、配線時はセンターピンと外周端子だけを使用
   Amazon検索:
   https://www.amazon.co.jp/s?k=DC-022B+5.5+2.1+パネルジャック

3. モーメンタリー・フットスイッチ: 1個
   必須条件:
   - 押している間だけ導通するモーメンタリーNO
   - ねじ軸M12、ケース穴12.4mm
   - 3mm厚のフタへ固定できるねじ軸長
   - ラッチ式、3PDTオルタネートは購入しない
   Amazon検索:
   https://www.amazon.co.jp/s?k=M12+モーメンタリー+フットスイッチ+NO

4. エレクトレットマイクカプセル: 1個
   必須条件:
   - 2線式
   - 直径6mm、高さ5mm程度
   - マイクアンプモジュール付きではなくカプセル単体
   Amazon検索:
   https://www.amazon.co.jp/s?k=エレクトレットコンデンサマイク+6x5mm+2線

5. 1x20ピン・2.54mmピッチ雌ソケット: 2本
   必須条件:
   - 1列20ピン
   - 2.54mmピッチ
   - 基板へスルーホールはんだ付けできるストレート型
   - ESP32を抜き差しできる雌ソケット
   Amazon検索:
   https://www.amazon.co.jp/s?k=1x20+2.54mm+ピンソケット+ストレート

6. KF128-2P端子台: 5個
   必須条件:
   - 2極
   - 2.54mmピッチ
   - 基板実装用
   - 5.08mmピッチ品はPCBに合わないため購入しない
   Amazon検索:
   https://www.amazon.co.jp/s?k=KF128-2P+2.54mm

7. R-78E5.0-1.0: 1個
   必須条件:
   - RECOM R-78E5.0-1.0
   - 固定5V、1A、SIP-3
   - ピン1=IN、2=GND、3=OUT
   注意:
   - 外観が似た可変MP1584基板や7805リニアレギュレータへ変更しない。
   - Amazonに正規品がない場合はDigiKey、Mouser、マルツ等で型番指定購入する。
   Amazon検索:
   https://www.amazon.co.jp/s?k=R-78E5.0-1.0

購入前チェック
--------------
[ ] 音声ジャックのねじ部外径が9.5mm以下
[ ] DCジャックのねじ部外径が8.2mm以下
[ ] 各ジャックが3mm厚パネルに固定可能
[ ] フットスイッチがモーメンタリーNOでM12
[ ] 端子台が2.54mmピッチ（5.08mmではない）
[ ] 雌ソケットが1列20ピン、2.54mmピッチ
[ ] 電源が9Vセンターマイナス
[ ] R-78E5.0-1.0は型番完全一致

注文を分ける場合
----------------
- Amazon向き: ジャック、スイッチ、マイク、ソケット、端子台、ねじ、配線材、9V電源。
- 電子部品専門店向き: R-78E5.0-1.0。Amazonに正規型番がなければ無理に代用品を選ばない。
