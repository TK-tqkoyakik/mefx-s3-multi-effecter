MEFX-S3 届いた部品からの初回実装手順 14
====================================

目的
----
届いた部品を使って、まず1枚だけ安全に動作確認する。
最初から5枚全部を作らない。
ケースも後回しにして、基板を表向きで机上確認する。


今回使う基板データ
------------------
- 正式基板: docs/kicad/mefx_s3.kicad_pcb
- 最新製造データ: docs/pcb-assembly/07_order_package/
- 端子・外部配線確認: docs/pcb-assembly/07_order_package/全パッド接続一覧_07.csv

基板データ上の重要接続:

U5 R-78E5.0-1.0
- Pad 1: +9V_PROT
- Pad 2: GND
- Pad 3: +5V

J1 9V DC
- J1-1: +9V_RAW
- J1-2: GND

J2 INPUT
- J2-1: INPUT_TIP
- J2-2: GND

J3 ELECTRET MIC
- J3-1: MIC_BIAS
- J3-2: GND

J4 FOOTSW
- J4-1: FOOTSW_GPIO
- J4-2: GND

J5 OUTPUT
- J5-1: OUTPUT_TIP
- J5-2: GND

J1からJ5の穴数:
- 各コネクタは2穴だけ。
- 穴ピッチは2.54mm。
- 4本足の端子台は、そのままでは基板へ刺さらない。


絶対に守ること
--------------
1. ESP32は、電源確認が終わるまで挿さない。
2. 9Vを入れる前に、テスターで短絡確認する。
3. R-78E5.0-1.0は向きを間違えない。
4. 9V電源はセンターマイナス。
5. DCジャックは見た目で判断せず、テスターで中心端子と外周端子を確認してから配線する。
6. まず1枚だけ作る。成功してから残りを考える。
7. 4本足の端子台を、無理に押し込まない。


R-78E5.0-1.0の向き
------------------
R-78E5.0-1.0は3本足。
部品データ上の標準ピンは以下。

- Pin 1: VIN
- Pin 2: GND
- Pin 3: VOUT

基板U5のパッドは以下。

- U5 Pad 1: +9V_PROT
- U5 Pad 2: GND
- U5 Pad 3: +5V

つまり、R-78の Pin 1 を基板U5の四角パッド/1番へ入れる。
中央がGND、反対端が+5V出力。

間違えると5Vが出ないだけでなく、U4、U2、ESP32側を壊す可能性がある。
ここは一番ゆっくり確認する。


今日の実装順
------------

Step 0: 作業前の確認
--------------------
- 作業台に金属くずがないこと。
- 基板の下に厚紙、木板、樹脂板など絶縁物を置く。
- 使う基板は1枚だけ出す。
- テスターを導通モードにする。
- はんだごて、はんだ、フラックス、ニッパーを準備する。


Step 1: PCBA済み基板の目視確認
------------------------------
電源は入れない。

確認すること:
- U1、U2、U4、D1が取れていない。
- ICの足どうしにはんだブリッジがない。
- 小さいコンデンサや抵抗が斜めに浮いていない。
- 四隅の穴や基板端に割れがない。

ここで明らかに部品が曲がっている、足がつながっている、部品がない場合は止める。


Step 2: U3 ESP32ソケットをはんだ付け
------------------------------------
部品:
- 1x20ピン 2.54mmピッチ雌ソケット x2

手順:
1. U3位置へソケット2本を挿す。
2. ESP32をソケットへ軽く挿して、2本のソケットを平行にする。
3. ESP32は治具として使うだけ。まだ電源は入れない。
4. ソケットの端のピンだけ仮はんだする。
5. 曲がりがなければ、ESP32を抜く。
6. 残りのピンを全部はんだ付けする。

ESP32の向き:
- 後で挿す時、USB端子を基板左側の「USB」「ESP32 USB THIS SIDE」表示側へ向ける。
- 裏面には挿さない。


Step 3: U5 R-78E5.0-1.0をはんだ付け
------------------------------------
部品:
- R-78E5.0-1.0 x1

手順:
1. R-78のPin 1を確認する。
2. 基板U5の四角パッド/1番を確認する。
3. Pin 1 -> U5 Pad 1へ入れる。
4. Pin 2 -> U5 Pad 2。
5. Pin 3 -> U5 Pad 3。
6. 1本だけ仮はんだして、向きと傾きを再確認する。
7. 問題なければ3本ともはんだ付けする。

はんだ後の確認:
- U5 Pad 1 と Pad 2 が短絡していない。
- U5 Pad 2 と Pad 3 が短絡していない。
- U5 Pad 1 と Pad 3 が短絡していない。


Step 4: J1の接続方法を選ぶ
--------------------------
部品:
- 2.54mm 2極端子台、または短い仮配線

重要:
- 現在の基板J1は2穴だけ。
- 端子台が4本足なら、そのまま付けない。
- 無理に刺す、基板へ追加穴を開ける、足を曲げて押し込む、はしない。

J1:
- J1-1: +9V_RAW
- J1-2: GND

おすすめ順:

方法A: 仮配線で進める
- J1-1とJ1-2へ短い線を直接はんだ付けする。
- その線をDCジャックへつなぐ。
- 初回電源確認にはこれが一番安全。

方法B: 4本足端子台を加工して使う
- 4本のうち、2.54mm間隔でJ1の2穴に合う2本だけを残す。
- 残す2本が別々の極であることをテスターで確認する。
- 同じ極どうしの2本を残すとショートではないが、電源入力として機能しない。
- 使わない足は根元近くで切る。
- 切った金属片が基板に残らないように片付ける。
- 強度が落ちるため、動作確認後にホットボンドなどで軽く固定する。

方法C: 2本足の別端子台に変える
- 2.54mmピッチ、2極、足が2本だけの端子台またはピンヘッダに変える。
- 今後の作業は一番きれい。

初回は方法Aを推奨する。


Step 5: 電源を入れない短絡チェック
----------------------------------
電源を接続しない。
ESP32も挿さない。

テスター導通モードで確認:

1. J1-1 と J1-2
   - 導通しないこと。

2. U5 Pin 1 と U5 Pin 2
   - 導通しないこと。

3. U5 Pin 3 と U5 Pin 2
   - 導通しないこと。

4. J1-2 と基板GND
   - 導通してよい。

どれか不安なら、電源を入れずに写真を送る。


Step 6: DCジャックをJ1へ仮配線
------------------------------
センターマイナスなので、配線はこうする。

- DCジャック外周端子 -> J1-1 / +9V_RAW
- DCジャック中心端子 -> J1-2 / GND

重要:
- DCジャックの端子形状だけで判断しない。
- DCプラグを挿した状態でテスターを使い、
  「プラグ外周とつながる端子」
  「プラグ中心とつながる端子」
  を確認してから配線する。
- 3端子ジャックのスイッチ端子は使わない。


Step 7: 初回電源確認
--------------------
ESP32はまだ挿さない。

手順:
1. 9Vアダプターをコンセントに挿す前に、極性をテスターで確認する。
   - プラグ中心: マイナス
   - プラグ外周: プラス
2. J1へDCジャックをつなぐ。
3. 9Vを入れる。
4. 異臭、発熱、煙、LEDの異常があればすぐ抜く。

測定:
- J1-1 と GND: 約 +9V
- U5 Pin 1 と GND: 約 +9V
- U5 Pin 3 と GND: 約 +5V

結果:
- +5Vが4.8Vから5.2V付近なら次へ進む。
- 0V、9Vのまま、5.5V以上、発熱がある場合は止める。


Step 8: 3.3V系を確認
--------------------
ESP32はまだ挿さない。

U4の出力、または3.3V系のコンデンサで約3.3Vが出ているか確認する。
細かいパッドを測るのが怖い場合は無理に測らない。
ショートさせるくらいなら、この段階は飛ばしてよい。

目安:
- +3V3_LOGIC と GND: 約 +3.3V


Step 9: ESP32を挿して起動確認
-----------------------------
1. いったん9Vを抜く。
2. ESP32をU3ソケットへ挿す。
3. USB端子は基板左側の「USB」「ESP32 USB THIS SIDE」側。
4. ピンが1列ずれていないか横から見る。
5. 9Vを入れる。
6. ESP32のLEDやPC接続状態を確認する。

ここで起動しない場合:
- すぐ9Vを抜く。
- ESP32の向き、ピンずれ、U5の5Vを確認する。


Step 10: J2からJ5を付ける
-------------------------
電源確認が成功してから、残りの接続を作る。
ここでも4本足端子台をそのまま付けない。

おすすめ:
- まずはJ2からJ5も短い線を直接はんだ付けして机上テストする。
- 端子台を使う場合は、J1と同じように2本だけ残すか、2本足端子台へ変更する。

J2 INPUT:
- J2-1 -> INPUTジャック TIP
- J2-2 -> INPUTジャック SLEEVE/GND

J3 MIC:
- J3-1 -> マイク +
- J3-2 -> マイク -

J4 FOOTSW:
- J4-1 -> スイッチ片側
- J4-2 -> スイッチ反対側
- 極性なし。

J5 OUTPUT:
- J5-1 -> OUTPUTジャック TIP
- J5-2 -> OUTPUTジャック SLEEVE/GND


Step 11: 外部部品の仮配線
------------------------
ケースに固定せず、机上で短い線で配線する。

INPUT/OUTPUTジャック:
- TIPはプラグ先端。
- SLEEVEはプラグ根元/外周。
- テスターで確認してから配線する。

フットスイッチ:
- 押したときだけ導通する2端子を使う。
- 押していない時に導通する端子は使わない。

マイク:
- 外装につながる端子がマイナス/GNDのことが多い。
- 迷ったらマイクは後回しでよい。


今日の停止ポイント
------------------
次のどれかで止めて、写真か測定値を送る。

- J1-1とJ1-2が導通する。
- U5の向きが少しでも不安。
- 9V電源の極性がセンターマイナスか分からない。
- U5 Pin 3で+5Vが出ない。
- R-78、U4、U2、ESP32が熱い。
- ESP32を挿したらLEDがつかない、またはPCに認識されない。


最初にCodexへ送るとよい報告
----------------------------
Step 7まで終わったら、次の形で送る。

J1-1 to GND: __ V
U5 Pin 1 to GND: __ V
U5 Pin 3 to GND: __ V
発熱: なし / あり
ESP32: まだ挿してない

この値が正しければ、ESP32を挿す段階へ進める。
