MEFX-S3 直配線接続表 16
======================

作成日: 2026-07-20

結論
----
4本足端子台は使わず、J1からJ5の2穴へ線を直接はんだ付けして進める。
今はケースも端子台も後回し。
まず1枚目の基板で「9V入力、5V生成、ESP32起動、スイッチ、音声入出力」を確認する。


作業時の基板の向き
------------------
- 基板は部品が載っている面を上にする。
- ESP32のUSB端子は、基板左側の「USB」「ESP32 USB THIS SIDE」表示側に向ける。
- J1からJ5はそれぞれ2穴。
- 1番ピンは四角いランド、または基板データ上のPad 1。
- 2番ピンはその隣の丸いランド。
- 迷ったら、写真を送って確認してからはんだ付けする。


買った部品と基板上の接続先
--------------------------

1. R-78E5.0-1.0 固定5V DC/DC
-----------------------------
基板位置:
- U5

接続:
- R-78 Pin 1 / VIN  -> U5 Pad 1 / +9V_PROT
- R-78 Pin 2 / GND  -> U5 Pad 2 / GND
- R-78 Pin 3 / VOUT -> U5 Pad 3 / +5V

注意:
- U5 Pad 1は四角ランド。
- 逆向き禁止。
- これを間違えると5V系、ESP32、U4、U2を壊す可能性がある。


2. ESP32-S3 Board Lite
----------------------
基板位置:
- U3

使う部品:
- 1x20ピン 2.54mm雌ソケット x2

接続:
- ESP32を直接はんだ付けしない。
- まずU3へ雌ソケット2本をはんだ付けする。
- 電源確認が終わってからESP32を差し込む。

向き:
- ESP32のUSB端子 -> 基板左側の「USB」「ESP32 USB THIS SIDE」表示側。
- 裏面には挿さない。
- 1列ずれて挿さない。


3. 9V DCジャック
----------------
基板位置:
- J1

基板データ:
- J1-1: +9V_RAW
- J1-2: GND

直配線:
- J1-1 -> 赤線 -> DCジャック外周端子
- J1-2 -> 黒線 -> DCジャック中心端子

9Vアダプター:
- センターマイナス。
- プラグ中心がマイナス。
- プラグ外周がプラス。

重要:
- DCジャックの端子は見た目で決めない。
- DCプラグを挿した状態でテスター導通確認する。
- 「プラグ外周につながる端子」をJ1-1へ。
- 「プラグ中心につながる端子」をJ1-2へ。
- 3端子DCジャックのスイッチ端子は使わない。


4. INPUT 6.35mmモノラルジャック
-------------------------------
基板位置:
- J2

基板データ:
- J2-1: INPUT_TIP
- J2-2: GND

直配線:
- J2-1 -> 白線 -> INPUTジャック TIP端子
- J2-2 -> 黒線 -> INPUTジャック SLEEVE端子

ジャック側:
- TIP = ギター/ベースプラグの先端につながる端子。
- SLEEVE = プラグ根元、ジャック外周金属につながる端子。

確認:
- プラグを挿した状態で、プラグ先端と導通する端子がTIP。
- プラグ根元と導通する端子がSLEEVE。


5. OUTPUT 6.35mmモノラルジャック
--------------------------------
基板位置:
- J5

基板データ:
- J5-1: OUTPUT_TIP
- J5-2: GND

直配線:
- J5-1 -> 青線 -> OUTPUTジャック TIP端子
- J5-2 -> 黒線 -> OUTPUTジャック SLEEVE端子

確認:
- J5へつないだジャックがOUTPUT。
- ケースの左右では決めない。


6. フットスイッチ / 仮押しボタン
-------------------------------
基板位置:
- J4

基板データ:
- J4-1: FOOTSW_GPIO
- J4-2: GND

直配線:
- J4-1 -> 黄線 -> スイッチNO接点の片側
- J4-2 -> 黒線 -> スイッチNO接点の反対側

注意:
- 極性なし。
- 押した時だけJ4-1とJ4-2が導通する端子を使う。
- 押していない時から導通する端子は使わない。
- 初回確認はフットスイッチでなく、普通のモーメンタリ押しボタンでもよい。


7. エレクトレットマイク
----------------------
基板位置:
- J3

基板データ:
- J3-1: MIC_BIAS
- J3-2: GND

直配線:
- J3-1 -> 緑線 -> マイク +
- J3-2 -> 黒線 -> マイク -

注意:
- 一般的な2線式エレクトレットマイクは、外装につながる端子がマイナス/GND。
- マイクは初回電源確認には不要。
- 電源、ESP32、スイッチ確認が終わってから付ける。


作る順番
--------

Step 1: U3ソケット
- 1x20雌ソケット2本をU3へはんだ付け。
- ESP32はまだ挿さない。

Step 2: U5 R-78E5.0-1.0
- Pin 1 -> U5 Pad 1。
- Pin 2 -> U5 Pad 2。
- Pin 3 -> U5 Pad 3。

Step 3: J1だけ直配線
- J1-1へ赤線。
- J1-2へ黒線。
- DCジャックへつなぐ。

Step 4: ESP32なしで電源確認
- J1-1 to GND: 約+9V
- U5 Pin 1 to GND: 約+9V
- U5 Pin 3 to GND: 約+5V
- ここで5Vが正しく出るまでESP32は挿さない。

Step 5: ESP32を挿す
- 9Vを抜く。
- ESP32をU3へ挿す。
- USB端子を基板左側へ向ける。
- 9Vを入れて起動確認。

Step 6: J4スイッチ
- J4-1とJ4-2をスイッチへ配線。
- 押した時だけ導通するか確認。

Step 7: J2 INPUT、J5 OUTPUT
- J2を入力ジャックへ。
- J5を出力ジャックへ。
- TIP/SLEEVEを必ずテスターで確認。

Step 8: J3マイク
- 最後でよい。


今すぐつなぐ場所だけ
--------------------
最初に必要なのはこの3か所だけ。

1. U5
- R-78 Pin 1 -> U5-1
- R-78 Pin 2 -> U5-2
- R-78 Pin 3 -> U5-3

2. U3
- 20ピンソケット x2をU3へ
- ESP32はまだ挿さない

3. J1
- J1-1 -> DCジャック外周
- J1-2 -> DCジャック中心

ここまでで止めて、5V確認する。


確認して送ってほしい値
----------------------
ESP32を挿す前:

J1-1 to GND: __ V
U5 Pin 1 to GND: __ V
U5 Pin 3 to GND: __ V
発熱: なし / あり
異臭: なし / あり
ESP32: まだ挿していない

この値がOKなら次へ進む。
