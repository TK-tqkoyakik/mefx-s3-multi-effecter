MEFX-S3 本体設計 最小構成
==========================

目的
----
まず実際に音が出る試作機を作るため、部品を必要最低限に絞った本体設計です。
保護や高級な電源分離はあとで追加できます。最初は、抵抗・コンデンサで代用できるところは代用します。


残す主要部品
------------
- ESP32-S3開発ボード
- PCM1808 ADC I2Sモジュール
- PCM5102A DAC I2Sモジュール
- TL072 DIP-8
- MP1584 5V降圧モジュール
- 1N5819ショットキーダイオード
- 6.35mmモノラルジャック 2個
- 9Vセンターマイナス電源 + DCジャック
- モーメンタリーフットスイッチ
- アナログマイクモジュール
- 抵抗/コンデンサ


部品の基本指定
--------------
- 抵抗:
  すべて 1/4W 金属皮膜 1% 推奨です。
  1/6Wでも動作はしますが、買うなら1/4Wの方が扱いやすいです。

- セラミックコンデンサ:
  10nFと100nFはすべてセラミック50Vに統一します。
  100nFは電源、仮想GND、スイッチ、入力カップリング C10 まで共通で使います。

- フィルムコンデンサ:
  1uFだけフィルム50Vにします。
  C13、C17 の音声カップリングに使います。
  耐圧は50V以上推奨です。

- 電解コンデンサ:
  10uF、47uF、100uFはすべて普通の電解16V以上に統一します。
  5V/3.3Vまわりにも16V品を使って、購入する種類を減らします。
  PCM5102AはGND中心のライン出力なので、最小構成では出力カップリング C22 を使いません。


省略または代用する部品
----------------------
- TLE2426 rail splitter:
  10kΩ 1/4W + 10kΩ 1/4W + 47uF電解16V以上 + 100nFセラミック50Vで仮想GNDを作って代用します。

- フェライトビーズ:
  10Ω 1/4W金属皮膜抵抗で代用します。

- 3.3V専用レギュレーター:
  ESP32-S3開発ボードの3.3Vピンを使います。

- TVSダイオード:
  最小試作では省略します。製品化前に追加します。

- ポリスイッチ:
  最小試作では省略します。製品化前に追加します。

- I2S信号の33Ω直列抵抗:
  最初は短い配線で直結します。動作不安定なら追加します。

- 入力の220pF、帰還の47pF:
  ノイズや発振が出たら追加します。


電源
----
9V DCジャックはエフェクター用センターマイナスです。

- DCジャック中心: GND
- DCジャック外側/スリーブ: +9V

配線:

1. DCジャック外側/スリーブ -> D1 1N5819 -> +9V_PROT
2. DCジャック中心 -> GND
3. +9V_PROT -> MP1584 IN+
4. GND -> MP1584 IN-
5. MP1584 OUT+ -> +5V
6. MP1584 OUT- -> GND
7. +5V -> ESP32-S3 VIN/5V
8. ESP32-S3 3V3 -> +3V3_LOGIC
9. +9V_PROT -> R8 10Ω -> +9VA
10. +9VA -> TL072 pin8
11. GND -> TL072 pin4

電源コンデンサ:

1. +9V_PROT -> C1 100uF 電解 16V以上 -> GND
2. +9V_PROT -> C2 100nF セラミック 50V -> GND
3. +9VA -> C3 47uF 電解 16V以上 -> GND
4. TL072 pin8付近の+9VA -> C4 100nF セラミック 50V -> GND
5. +5V -> C5 100uF 電解 16V以上 -> GND
6. +5V -> C6 100nF セラミック 50V -> GND
7. +3V3_LOGIC -> C7 10uF 電解 16V以上 -> GND
8. +3V3_LOGIC -> C8 100nF セラミック 50V -> GND

仮想GND:

1. +9VA -> R50 10kΩ 1/4W金属皮膜 -> VBIAS_4V5
2. VBIAS_4V5 -> R51 10kΩ 1/4W金属皮膜 -> GND
3. VBIAS_4V5 -> C9A 47uF 電解 16V以上 -> GND
4. VBIAS_4V5 -> C9B 100nF セラミック 50V -> GND

確認:

- +5Vが5.0V付近であること
- +3V3_LOGICが3.3V付近であること
- VBIAS_4V5が4.5V付近であること
- TL072 pin8が+9V付近、pin4がGNDであること


入力プリアンプ
--------------
TL072のA側をギター/ベース入力用に使います。

TL072 DIP-8ピン:

1. pin1: A OUT
2. pin2: A IN-
3. pin3: A IN+
4. pin4: GND
5. pin5: B IN+
6. pin6: B IN-
7. pin7: B OUT
8. pin8: +9VA

配線:

1. INPUTジャック Sleeve -> GND
2. INPUTジャック Tip -> R1 1MΩ 1/4W金属皮膜 -> GND
3. INPUTジャック Tip -> C10 100nF セラミック 50V -> IN_AC
4. IN_AC -> R2 1MΩ 1/4W金属皮膜 -> VBIAS_4V5
5. IN_AC -> R3 1kΩ 1/4W金属皮膜 -> TL072 pin3 A IN+
6. TL072 pin1 A OUT -> R4 100kΩ 1/4W金属皮膜 -> TL072 pin2 A IN-
7. TL072 pin2 A IN- -> R5 100kΩ 1/4W金属皮膜 -> VBIAS_4V5

ゲイン:

1 + R4/R5 = 2倍


ADC入力
-------
PCM1808の左チャンネルを楽器、右チャンネルをマイクに使います。

PCM1808モジュールの電源:

1. PCM1808 VCC/5V -> +5V
2. PCM1808 VDD/3V3 -> +3V3_LOGIC
3. PCM1808 AGND/DGND/GND -> GND
4. PCM1808 VREFに外付け部品が必要なモジュールの場合:
   VREF -> 100nF セラミック 50V -> GND
   VREF -> 10uF 電解 16V以上 -> GND
   すでにモジュール上に実装済みなら追加しません。

楽器:

1. TL072 A OUT -> C13 1uF フィルム 50V -> R6 100Ω 1/4W金属皮膜 -> PCM1808 LIN
2. PCM1808 LIN -> C14 10nF セラミック 50V -> GND

マイク:

1. アナログマイクモジュール VCC -> +3V3_LOGICまたは+5V
2. アナログマイクモジュール GND -> GND
3. アナログマイクモジュール OUT -> C17 1uF フィルム 50V -> R7 100Ω 1/4W金属皮膜 -> PCM1808 RIN
4. PCM1808 RIN -> C18 10nF セラミック 50V -> GND

注意:

- マイクはI2S/PDMではなく、アナログOUT付きのモジュールを使います。
- PCM1808はSCKI/MCLK端子があるモジュールを選びます。
- PCM1808の FMT/MD0/MD1 は、モジュールのジャンパーや抵抗で I2S/スレーブ動作になるように設定します。
  IC単体で組む場合は、各制御ピンを10kΩでVDDまたはGNDへ固定します。


I2S配線
-------
ESP32-S3をI2Sマスターにします。
ファームウェア側も同じピン割り当てにしています。

1. ESP32 GPIO17 MCLK -> PCM1808 SCKI
2. ESP32 GPIO4 BCLK -> PCM1808 BCK + PCM5102A BCK
3. ESP32 GPIO5 LRCK -> PCM1808 LRCK + PCM5102A LRCK
4. PCM1808 DOUT -> ESP32 GPIO6
5. ESP32 GPIO16 DOUT -> PCM5102A DIN

PCM5102Aモジュールの電源/設定:

1. PCM5102A VCC/3V3 -> +3V3_LOGIC
   5V入力対応モジュールでも、最初は3.3Vで使う方がESP32とロジック電圧をそろえやすいです。
2. PCM5102A GND -> GND
3. PCM5102A SCK -> GND
   SCKをGNDにして、PCM5102A内部PLLがBCLK/LRCKから動く3線I2Sとして使います。
4. PCM5102A XSMT/XMT が露出している場合 -> R30 10kΩ 1/4W金属皮膜 -> +3V3_LOGIC
   XSMTがLowのままだとミュートされます。

短い配線なら最初は直結します。
動作が不安定なら、各I2S信号に33Ω直列抵抗を追加します。
図面の R20〜R24 は最小構成ではジャンパー線です。33Ω抵抗は、I2Sが不安定な場合だけ追加します。


DAC出力
-------
PCM5102AはGND中心のライン出力を持つため、最小構成ではTL072のB側出力バッファを使いません。
PCM5102A LOUTを100Ω経由でOUTPUTジャックへ出します。

配線:

1. PCM5102A LOUT -> R35 100Ω 1/4W金属皮膜 -> OUTPUTジャック Tip
2. OUTPUTジャック Tip -> R36 100kΩ 1/4W金属皮膜 -> GND
3. OUTPUTジャック Sleeve -> GND

TL072 B側の未使用処理:

1. TL072 pin5 B IN+ -> VBIAS_4V5
2. TL072 pin6 B IN- -> TL072 pin7 B OUT 直結

確認:

- アンプにつなぐ前にOUTPUT TipのDC電圧を測ります。
- 大きなDCが出ている場合は接続しません。
- 音量が大きすぎる場合は、まずWebアプリ/ファームウェア側で出力レベルを下げます。


フットスイッチ
--------------
GPIO0は使いません。GPIO9を使います。

配線:

1. +3V3_LOGIC -> R40 10kΩ 1/4W金属皮膜 -> GPIO9
2. GPIO9 -> SW1 -> GND
3. GPIO9 -> C30 100nF セラミック 50V -> GND


最初に確認する順番
------------------
1. 9V電源の極性を確認
2. MP1584を5.0Vに調整
3. +3V3_LOGICを確認
4. VBIAS_4V5を確認
5. TL072の電源ピンを確認
6. 入力プリアンプだけ動作確認
7. PCM1808/PCM5102A/ESP32を接続
8. 小音量で出力確認
