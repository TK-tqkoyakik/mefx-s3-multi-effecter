R-78E5.0-1.0 の向き

部品の足を下にして、印字面を正面から見る。
この見方で左から順に:

1番足: +Vin
2番足: GND
3番足: +5V

基板側では:

U5-1: 四角ランド / +9V_PROT
U5-2: GND
U5-3: +5V

つまり、R-78の1番足をU5の四角ランドへ入れる。


最初に作る場所

1. U3 ESP32用ソケット
   - 20ピンの雌ソケットを左右2本取り付ける。
   - ESP32本体は、電源確認が終わるまで挿さない。

2. U5 R-78E5.0-1.0
   - 1番足をU5の四角ランドへ入れる。
   - 無理に曲げず、3本足が自然に穴へ入る向きで取り付ける。

3. J1 9V入力だけ直配線
   - J1-1: 赤線 -> DCジャック外周 / +9V
   - J1-2: 黒線 -> DCジャック中心 / GND
   - センターマイナスなので、中心がGND。


最初の停止位置

U3ソケット、U5、J1だけ付けたら一度止める。
ESP32を挿さずに電源を入れて、テスターで以下を確認する。

1. J1-1 と GND の間: 約 +9V
2. U5-1 と GND の間: 約 +9V
3. U5-3 と GND の間: 約 +5V

ここが合ってからESP32を挿す。
5Vが出ていない、または極性が逆なら、ESP32は絶対に挿さない。
