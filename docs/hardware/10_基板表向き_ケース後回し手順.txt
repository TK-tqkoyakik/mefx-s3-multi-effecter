MEFX-S3 基板表向き・ケース後回し手順 10
======================================

今回の方針
----------
ケースは後回し。
まず基板を表向きで机上に置いて、電源、ESP32、フットスイッチ、音声入出力を確認する。

この段階ではケース穴の左右やジャック位置を考えない。
基板を壊さず、電気的に正しく動くかを先に見る。


置き方
------
- 基板は部品面を上にする。
- ESP32-S3も表側のU3ソケットへ挿す。
- 基板の下には絶縁できるものを置く。
  - 厚紙
  - 樹脂板
  - ゴム足
  - きれいな木板
- 金属机や工具の上に直接置かない。


この段階でケースに固定しないもの
------------------------------
- INPUT 6.35mmジャック
- OUTPUT 6.35mmジャック
- DCジャック
- フットスイッチ
- マイク

これらはケースに固定せず、短い仮配線で机上確認する。


配線先
------
J1 9V DC:
- J1-1 -> DCジャック外周端子（+9V）
- J1-2 -> DCジャック中心端子（GND）

J2 INPUT:
- J2-1 -> INPUTジャック TIP
- J2-2 -> INPUTジャック SLEEVE

J3 MIC:
- J3-1 -> マイク +
- J3-2 -> マイク -

J4 FOOTSW:
- J4-1 -> フットスイッチNO接点の片側
- J4-2 -> フットスイッチNO接点の反対側

J5 OUTPUT:
- J5-1 -> OUTPUTジャック TIP
- J5-2 -> OUTPUTジャック SLEEVE


最初にやる確認
--------------
1. ESP32を挿さない。
2. 9Vも入れない。
3. テスターでJ1-1/J1-2が短絡していないことを確認する。
4. DCプラグ外周がJ1-1へ導通することを確認する。
5. DCプラグ中心がJ1-2へ導通することを確認する。
6. INPUT/OUTPUTのTIP/SLEEVEをテスターで確認する。
7. フットスイッチは押したときだけJ4-1/J4-2が導通することを確認する。


電源確認
--------
1. ESP32を挿さないまま9Vを入れる。
2. J1-1対GNDが約+9Vであることを確認する。
3. U5出力が約+5Vであることを確認する。
4. 異臭、発熱、大電流があればすぐ電源を切る。
5. 問題なければ電源を切る。
6. ESP32を表側ソケットへ挿す。
7. 再度9Vを入れてESP32が起動するか確認する。


ケースへ進む条件
----------------
- 9V極性が正しい。
- 5Vが出ている。
- ESP32が起動する。
- フットスイッチ入力が読める。
- INPUT/OUTPUTの配線ミスがない。
- 音声入出力の確認に進める。

ここまでできてからケース穴と取り付け位置を考える。
ケースは後で合わせる。基板を優先する。
