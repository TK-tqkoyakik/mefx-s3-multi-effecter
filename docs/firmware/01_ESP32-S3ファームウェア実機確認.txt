MEFX-S3 ESP32-S3 ファームウェア実機確認 01
===========================================

確認日
------
2026-06-25

対象
----
- ESP32-S3: Freenove ESP32-S3 Board Lite
- 接続ポート: COM5 (USB-Enhanced-SERIAL CH343)
- ESP-IDF: 6.0.1
- 音声形式: 48 kHz / 32 bit / stereo I2S
- BLE名: MEFX-S3

基板と一致するGPIO
------------------
- GPIO17: CS4270 MCLK
- GPIO4: CS4270 BCLK
- GPIO5: CS4270 LRCK
- GPIO6: CS4270 ADC_DOUT -> ESP32入力
- GPIO16: ESP32出力 -> CS4270 DAC_DIN
- GPIO15: CS4270 RESET
- GPIO9: フットスイッチ

今回の軽量化
------------
- tone_eqを5タップ対称FIR畳み込みへ変更。
- 対称係数をまとめ、1サンプルあたり実質3回の係数乗算で処理。
- プリセット変更時だけDSP係数を計算。
- sinfによるLFOを三角波演算へ変更。
- tanhfによる歪みを軽量な有理式ソフトクリップへ変更。
- テレメトリ通知を約75回/秒から約10回/秒へ削減。
- 使用コンポーネントだけを対象にするCMake構成へ変更。

フットスイッチ
--------------
- 短押し: 次の保存済みプリセットへ移動。
- 長押し: 現在プリセットのバイパスを切り替え、同じNVS枠へ保存。
- 以前のように長押しごとに新しい保存枠を消費しない。

ビルド結果
----------
- ビルド成功。
- mefx_s3.bin: 485,440 bytes。
- アプリ領域空き: 約68%。
- ESP32-S3への書き込みとハッシュ検証成功。

起動確認
--------
- BLEサービス初期化: 成功。
- BLE広告開始: 成功。
- CS4270リセット解除: 成功。
- I2S初期化: 成功。
- MEFX-S3メイン処理開始: 成功。

基板到着後の確認順
------------------
1. ESP32-S3を外した状態で3.3V、5V、GNDの短絡がないことを確認する。
2. 基板へ9Vを入れ、5Vと3.3Vをテスターで測る。
3. 電源を切ってESP32-S3をソケットへ正しい向きで装着する。
4. USBを接続し、起動ログにI2S初期化エラーがないことを確認する。
5. PCのBluetooth一覧またはWebアプリからMEFX-S3を確認する。
6. 入力を無音にした状態で出力ノイズと異常発熱を確認する。
7. 楽器入力を接続し、バイパスから小さい音量で試す。
8. tone_eqを0、50、100に変え、FIR音色変化を確認する。
9. フットスイッチの短押しと長押しを確認する。

注意
----
今回の実機確認はESP32-S3開発ボード単体で実施した。
CS4270とアナログ回路を含む音声入出力の実測は、製造基板到着後に行う。
