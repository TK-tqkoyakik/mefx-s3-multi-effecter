MEFX-S3 JLC3DPケース 04
======================

生成物
------
- mefx_case_bottom_jlc3dp.stl
  - 底箱。基板150x90mmを独立した4本のM3ねじで固定する。
- mefx_case_lid_jlc3dp.stl
  - フタ。中央にM12モーメンタリーフットスイッチ用の直径12.4mm穴。
- mefx_case_hole_template.svg
  - 穴位置と開口位置の確認用テンプレート。

JLCPCB/JLC3DP注文方針
--------------------
安価優先:
- 3D Printing
- SLA
- Standard Resin
- Standard surface finish

強度優先:
- 3D Printing
- MJF
- PA12-HP Nylon
- Standard surface finish

注意
----
- このケースは初回試作用。踏み込み強度や防塵防水は未検証。
- 入出力はREAN NYS229相当の6.35mmモノラル・パネルジャック（ねじ部外径9.5mm以下）を使用する。ケース穴は直径9.8mm。
- DC入力はDC-022B相当の5.5/2.1mmパネルジャック（ねじ部外径8.2mm以下）を使用する。ケース穴は直径8.5mm。
- フットスイッチはM12ねじ軸・モーメンタリーNO型（取付穴12.4mm）を使用する。
- 購入品の商品図で、ねじ部外径、3mm厚パネルへ固定できるねじ長、ナット外径を確認する。
- 入出力/DC穴の中心は底面から38mm。ジャック本体を基板より上へ逃がす配置とする。
- 底箱外寸は166x106x55mm、補強付きフタは高さ8mm。基板外周と内壁の間に5mmの余裕を確保。
- 基板上面からフタ下面まで約42mmを確保し、ESP32、DC/DC、フットスイッチ本体の干渉を避ける。
- フタ裏の十字リブが中央スイッチの踏み込み荷重を四方へ分散する。
- ケースは底箱とフタの2分割。四隅のM3ねじ4本だけで開閉できる。
- 基板固定ねじ4本はケース開閉ねじと独立しているため、フタを外しても基板は動かない。
- 底箱の8か所にM3用熱圧入インサートナット（外径4.6mm以下、長さ5mm）を取り付ける。
- フタ固定はM3x12mm、基板固定はM3x6mmのなべねじを各4本使用する。
- 樹脂へインサートを入れる際は温度を低めにし、垂直にゆっくり圧入する。初回は端材で確認する。
- JLC3DPへ出す前に、STLビューアで寸法と向きを確認する。
