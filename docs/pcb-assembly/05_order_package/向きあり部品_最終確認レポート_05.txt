MEFX-S3 PCBA 05 向きあり部品 最終確認レポート
=============================================

作成日
------
2026-06-26

結論
----
向きが問題になるSMT部品は、今回のBOMでは主に次の4種類。

- D1: SS14 ショットキーダイオード
- U1: TL072CDT オペアンプ
- U2: CS4270-CZZR オーディオCODEC
- U4: AP2112K-3.3TRG1 3.3V LDO

KiCad基板データ、BOM、CPL、LCSC登録データシートを照合した結果、
05データ上のピン番号とネット接続は正しい。

特に前回問題になったU4は、05で標準SOT-23-5フットプリントへ修正済み。
電気的接続も、AP2112K-3.3TRG1のSOT25ピン配置と一致している。

ただし、JLCPCBの部品モデル側の回転解釈は、アップロード後の2D/3D
プレビューが最終確認になる。注文前に本レポートの「JLCPCB画面での確認」を
必ず見ること。

1. U4 AP2112K-3.3TRG1 / C51118
------------------------------
役割:
+5V_AUDIOから+3V3_LOGICを作る3.3V LDO。

LCSC登録:
- C51118
- AP2112K-3.3TRG1
- SOT-25-5

データシート根拠:
- AP2112はSOT25を採用。
- Diodes資料では、以前SOT-23-5と呼ばれていたパッケージがSOT25へ名称変更されたと説明されている。
- SOT25のPin Descriptions:
  - Pin 1: VIN
  - Pin 2: GND
  - Pin 3: EN
  - Pin 4: NC
  - Pin 5: VOUT

05基板のU4:
- Footprint: Package_TO_SOT_SMD:SOT-23-5
- Pad size: 1.325mm x 0.600mm
- Pin pitch: 0.950mm
- CPL: U4, X=100.000mm, Y=-11.000mm, Top, Rotation=0.0

05基板ネット:
- Pad 1: +5V_AUDIO
- Pad 2: GND
- Pad 3: +5V_AUDIO
- Pad 4: NC
- Pad 5: +3V3_LOGIC

判定:
OK。
データシートの1=VIN,2=GND,3=EN,4=NC,5=VOUTと一致。
前回04のような「部品足がパッド外側に寄る」寸法問題は05で解消済み。

JLCPCB画面での確認:
- U4の5本の足が、5つのSOT-23-5パッド中央付近に乗ること。
- U4のPin 1マークが、Pad 1側に来ること。
- Pad 1側は+5V_AUDIO、Pad 5側は+3V3_LOGIC。
- もしU4が180度回って見える場合は、そのまま決済しない。

4. D1 SS14 / C2480
------------------
役割:
9V入力の逆接保護用ショットキーダイオード。

LCSC登録:
- C2480
- SS14
- SMA(DO-214AC)
- 40V / 1A

データシート根拠:
- Package: DO-214AC/SMA
- Polarity: Color band denotes cathode end
- SS14は40V品
- 平均整流電流1A

05基板のD1:
- Footprint: MEFX:D_SMA
- Pad size: 1.600mm x 1.800mm
- CPL: D1, X=78.000mm, Y=-10.000mm, Top, Rotation=0.0

05基板ネット:
- Pad 1: +9V_PROT
- Pad 2: +9V_RAW

判定:
OK。
基板上ではPad 1をカソード側として+9V_PROTへ接続している。
逆接保護の向きとして妥当。

JLCPCB画面での確認:
- D1本体の帯マークが+9V_PROT側に来ること。
- 帯マークが+9V_RAW側に見える場合は、そのまま決済しない。

向きなしとして扱える部品
------------------------
次の部品は通常のSMT実装では向きなし。

- 抵抗 R*
- 100nF/220pF/1uF/2.2nF/3.3nF/10uF/47uF のセラミックコンデンサ

注意:
電解コンデンサやタンタルではないため、極性方向はない。
ただし容量値とパッケージサイズはBOM上で確認済み。

注文前の最終判断
----------------
現時点の05ファイルは再注文可能。
ただし決済前にJLCPCBの2D/3Dプレビューで、以下を必ず確認する。

1. U4の足がSOT-23-5パッド中央付近に重なる。
2. U4のPin 1がPad 1側。
3. U2のPin 1マークがPad 1側。
4. U1のPin 1マークがPad 1側。
5. D1の帯マークが+9V_PROT側。
6. U1/U2/U4/D1が未実装扱いになっていない。
7. 古い04ファイルではなく、05のGerber/BOM/CPLを使っている。

もしプレビューで違和感がある場合
--------------------------------
すぐ注文しない。
スクリーンショットを保存して、次のどれかを判断する。

- 位置ずれ: CPL座標/回転の問題
- 足がパッドから外れる: フットプリント寸法の問題
- Pin 1や帯だけ逆: Rotationの問題
- 部品候補が違う: BOM/LCSC品番の問題

05ではU4寸法問題は修正済みなので、もしU4が再び合わない場合は、
JLCPCB側で旧04の部品配置情報を再利用していないかを最優先で疑う。
