MEFX-S3 PCBA 05 U4修正・最終確認書
=====================================

対象
----
U4: AP2112K-3.3TRG1
LCSC: C51118
機能: +5V_AUDIOから+3V3_LOGICを生成
パッケージ: SOT-23-5 / SOT-25

今回の修正
----------
旧U4は左右パッド中心間隔が3.800 mmで、JLCPCBの部品端子より外側に
広すぎる状態だった。

U4をKiCad 10標準ライブラリの次のフットプリントへ置換した。
Package_TO_SOT_SMD:SOT-23-5

修正版の寸法:
- 左右パッド中心間隔: 2.275 mm
- パッド寸法: 1.325 x 0.600 mm
- 縦方向ピッチ: 0.950 mm

U4ピンとネット
---------------
Pad 1: VIN  -> +5V_AUDIO
Pad 2: GND  -> GND
Pad 3: EN   -> +5V_AUDIO
Pad 4: NC   -> 未接続
Pad 5: VOUT -> +3V3_LOGIC

検査結果
--------
- KiCad DRC: 0 violations
- 未配線: 0
- KiCad ERC: 0 errors / 0 warnings
- U4 Pad 1～5のネット: 上記と一致
- BOM U4: AP2112K-3.3 / C51118 / SOT-23-5
- CPL U4: X=100.000 mm, Y=-11.000 mm, Top, Rotation=0.0
- PCB/BOM/CPLのSMT参照番号: 59個ですべて一致
- C51118確認日: 2026-06-25
- LCSC登録: AP2112K-3.3TRG1、SOT-25-5、販売中

向きの追加確認
--------------
- D1 / SS14: Pad 1がカソード、+9V_PROT側
- U1 / TL072CDT: Pad 1がTL072_A_OUT
- U2 / CS4270-CZZR: Pad 1がDAC_DIN

U2のDFM警告について
-------------------
U2は0.65 mmピッチのTSSOP-24で、パッド寸法は1.70 x 0.40 mm。
KiCad標準TSSOP-24の1.475 x 0.40 mmより長く、はんだ付け面積を確保している。
幅を0.45 mmへ増やす試験では隣接クリアランス違反が11件発生したため、
電気的クリアランスを守れる1.70 x 0.40 mmを維持した。

JLCPCB再アップロード時の確認
-----------------------------
1. UPLOAD_THIS_GERBER_05.zipを新規注文としてアップロードする。
2. UPLOAD_THIS_BOM_05.csvとUPLOAD_THIS_CPL_05.csvを指定する。
3. 古い注文の部品配置情報を再利用しない。
4. 2D/3DプレビューでU4の5本の足が各パッド中央付近に重なることを確認する。
5. U4のPin 1マークと基板シルクのPin 1マークが同じ側であることを確認する。
6. U1、U2、D1もPin 1またはカソードの向きを確認してから決済する。

注意
----
KiCad上のフットプリント、配線、DRC、BOM、CPLは検査済み。
JLCPCBの部品モデルとパッドの最終重なり表示は、JLCPCBへ再アップロードした
後のプレビューでのみ確定できるため、手順4の目視確認後に発注すること。
