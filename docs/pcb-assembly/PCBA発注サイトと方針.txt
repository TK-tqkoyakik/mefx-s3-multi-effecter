MEFX-S3 PCBA発注サイトと方針
=============================

候補サイト
----------
1. PCBWay
   URL: https://www.pcbway.com/pcb-assembly.html
   向いていること:
   - PCB製造
   - SMT実装
   - スルーホール実装
   - 部品調達
   - 見積もり時に相談しながら進める

   今回のおすすめ度:
   一番高いです。
   6.35mmジャック、フットスイッチ、モジュール類まで含めたい場合はPCBWayの方が相談しやすいです。

2. JLCPCB
   URL: https://jlcpcb.com/capabilities/pcb-assembly-capabilities
   向いていること:
   - 安いPCB製造
   - SMT部品の実装
   - LCSC/JLCPCB部品ライブラリにある部品の実装

   今回のおすすめ度:
   試作基板を安く作るなら良いです。
   ただし、大きいスルーホール部品、6.35mmジャック、フットスイッチ、各種モジュールは手はんだ前提にする方が安全です。

3. Seeed Fusion
   URL: https://www.seeedstudio.com/fusion_pcb.html
   向いていること:
   - PCB製造
   - 試作PCBA
   - Seeed系部品やモジュールを使う設計

4. Elecrow
   URL: https://www.elecrow.com/pcb-assembly.html
   向いていること:
   - PCB製造
   - PCBA
   - 小規模試作


今回の結論
----------
まずは PCBWay 向けの設計にします。

理由:
- 部品調達とスルーホール実装まで相談しやすい。
- 見積もり時に「この部品は実装可能/不可」を確認しやすい。
- モジュール類やジャック類が多い今回の構成に向いています。

ただし、費用を抑える場合は JLCPCB 向けに以下の分け方にします。

- JLCPCBに実装依頼:
  抵抗、セラミックコンデンサ、電解コンデンサ、ショットキーダイオード、TL072 SOIC-8。

- 自分で手はんだ:
  ESP32-S3開発ボード、PCM1808モジュール、PCM5102Aモジュール、MP1584モジュール、6.35mmジャック、DCジャック、フットスイッチ、マイクモジュール。


基板の考え方
------------
この基板は「完成エフェクター基板」ではなく、最初の発注向けの「キャリア基板」にします。

キャリア基板とは:
- 小さい部品は基板に実装する。
- 大きい部品やケースに固定する部品は、基板上の端子台/ピンヘッダに配線する。
- ケース寸法が未確定でも作れる。
- 部品を交換しやすい。

ケースに直接固定する部品:
- INPUT 6.35mmジャック
- OUTPUT 6.35mmジャック
- DCジャック
- フットスイッチ
- 必要ならマイク

基板に載せる/挿す部品:
- ESP32-S3開発ボード
- PCM1808 ADCモジュール
- PCM5102A DACモジュール
- MP1584 5V降圧モジュール
- TL072
- 抵抗/コンデンサ/ダイオード


発注に必要なファイル
--------------------
最終的に必要なもの:

1. Gerber ZIP
   PCB製造用。

2. Drill file
   穴あけ用。Gerber ZIPに含めます。

3. BOM CSV
   実装する部品表。

4. CPL / Pick and Place CSV
   SMT部品の配置座標。

5. Assembly drawing
   手はんだ部品、DNP部品、向きの説明。

6. 回路図PDF
   見積もり確認用。


今このフォルダで作ったもの
--------------------------
- PCBA_基板設計_v1.txt
  基板寸法、層構成、配置、配線ルール。

- PCBA_BOM_実装依頼.csv
  PCBWay/JLCPCBに実装依頼する候補部品。

- PCBA_手はんだ部品.csv
  モジュール、ジャック、スイッチなど、手で付ける部品。

- PCBA_ネットリスト.csv
  KiCadで回路図/基板を作るための接続表。


まだ必要な作業
--------------
この段階では、まだGerberはありません。
次にKiCadで以下を作ります。

1. 回路図
2. PCBレイアウト
3. DRC/ERC確認
4. Gerber出力
5. BOM/CPL出力

この次の作業で、実際に発注画面へアップロードできるファイル一式にします。
