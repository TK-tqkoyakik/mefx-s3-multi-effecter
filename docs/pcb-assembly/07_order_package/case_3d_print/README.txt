MEFX-S3 JLC3DPケース 07
======================

JLC3DPへアップロードするファイル
-------------------------------
1. mefx_case_bottom_jlc3dp.stl
2. mefx_case_lid_jlc3dp.stl

構成
----
- mefx_case_bottom_jlc3dp.stl
  - 底箱。
  - 150x90mm基板を4本のM3ねじで固定する。
  - 入力ジャック、出力ジャック、DCジャック、USB-C、マイク音孔の開口あり。
  - 現物組立では、入力/出力の左右名よりも「部品に干渉しない側」を優先する。
  - J2へ配線したジャックをINPUT、J5へ配線したジャックをOUTPUTとして扱う。
- mefx_case_lid_jlc3dp.stl
  - フタ。
  - 中央にM12モーメンタリーフットスイッチ用の直径12.4mm穴。
  - フットスイッチ荷重を分散する補強リブあり。

寸法
----
- 底箱外寸: 166 x 106 x 55 mm
- フタ外寸: 166 x 106 x 8 mm
- 基板: 150 x 90 mm
- ケース内の基板オフセット: X=8mm, Y=8mm
- 入力ジャック穴: 直径9.8mm
- 出力ジャック穴: 直径9.8mm
- DCジャック穴: 直径8.5mm
- フットスイッチ穴: 直径12.4mm
- マイク音孔: 直径4.0mm
- USB-C開口: 28 x 12 mm

JLC3DP注文方針
--------------
安価優先:
- 3D Printing
- SLA
- 9600 Resin または Standard Resin
- Standard surface finish

強度優先:
- 3D Printing
- MJF
- PA12-HP Nylon
- Standard surface finish

注意
----
- このケースは初回試作用。製品販売レベルの強度、防水、防塵は未検証。
- INPUT/OUTPUTジャックはケース左右だけで決めない。
  - ジャック本体が基板部品に当たらない側へ取り付ける。
  - J2へ配線したジャックがINPUT、J5へ配線したジャックがOUTPUT。
  - 左右が逆に見える場合は、外側ラベルと配線先を優先する。
- 入出力はREAN NYS229相当の6.35mmモノラル・パネルジャックを想定。
  - ジャックねじ部外径9.5mm以下なら9.8mm穴に入る。
- DC入力はDC-022B相当の5.5/2.1mmパネルDCジャックを想定。
  - ジャックねじ部外径8.2mm以下なら8.5mm穴に入る。
- フットスイッチはM12ねじ軸・モーメンタリーNO型を想定。
  - 取付穴12.4mm。
- 底箱の8か所にM3用熱圧入インサートナットを入れる。
  - 外径4.6mm以下、長さ5mmを想定。
- フタ固定はM3x12mmなべねじ x4。
- 基板固定はM3x6mmなべねじ x4。
- 購入品の商品図で、ねじ部外径、ナット外径、3mm厚パネル対応を確認してから注文する。
- 初回は寸法確認用試作として扱い、強く踏む前にフットスイッチ周辺のたわみを確認する。
