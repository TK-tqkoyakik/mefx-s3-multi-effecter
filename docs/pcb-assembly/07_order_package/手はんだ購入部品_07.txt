MEFX-S3 手はんだ・機構部品 07
================================

JLCPCB PCBAに含まれるもの
--------------------------
- PCB基板 x5
- SMT実装部品 22アイテム / 59個
- 抵抗、セラミックコンデンサ、U1、U2、U4、D1などの基板上SMD部品

JLCPCB PCBAに含まれないもの
----------------------------
以下は自分で購入して、基板またはケースへ取り付ける。

所持済み
--------
- Freenove ESP32-S3 Board Lite B0FRRH9NCP x1

基板へ手はんだする部品
----------------------
- R-78E5.0-1.0 固定5V DC/DC SIP-3 x1
- 1x20ピン 2.54mmピッチ ロープロファイル雌ソケット x2
- KF128-2P 2.54mmピッチ 2極ねじ端子台 x5

ケースへ取り付ける部品
----------------------
- REAN NYS229相当 6.35mmモノラル・パネルジャック x2
  - ねじ部外径9.5mm以下
- DC-022B相当 5.5/2.1mmパネルDCジャック x1
  - センターマイナス用
  - ねじ部外径8.2mm以下
- M12 モーメンタリーNOフットスイッチ x1
  - 取付穴12.4mm
  - ねじ軸長8mm以上
- 2線式エレクトレットマイクカプセル 6x5mm x1
- AWG24撚り線 適量
- 熱収縮チューブ 適量

ケース固定部品
--------------
- M3用熱圧入インサートナット x8
  - 外径4.6mm以下
  - 長さ5mm
- M3x12mm なべねじ x4
  - フタ固定用
- M3x6mm なべねじ x4
  - 基板固定用

電源
----
- 9V センターマイナス ACアダプタ x1
  - 安定化済み
  - 1A以上推奨

ケース
------
- JLC3DPへ別注文する場合:
  - mefx_case_bottom_jlc3dp.stl x1
  - mefx_case_lid_jlc3dp.stl x1
- すでにJLC3DPのカートへ入っていない場合、PCBA料金にはケースは含まれない。

数量の注意
----------
- JLCPCBの基板は5枚。
- 1台だけ完成させるなら上の数量でよい。
- 5台すべて完成させるなら、ESP32、DC/DC、ソケット、端子台、ジャック、
  フットスイッチ、マイク、ケース、ねじ類を5台分に増やす。

重要
----
- ジャックとスイッチは、商品図で取付穴径とパネル厚3mm対応を確認してから購入する。
- 9V電源は一般的なエフェクターと同じセンターマイナスを使う。
- ESP32-S3はJLCPCBでは実装されない。ソケットに後から差し込む。
